# The Catacombs 64

A first-person exploration game in a late-90s cartridge style. You start in a foggy swamp ringed by trees, find a straw hut, go down a concrete stair into a damp cobblestone hall, take a torch from the wall and open an iron skull door into the bone-lined Paris Catacombs. Five puzzle gates stand between you and daylight.

Play: https://optimusgrok.github.io/the-catacombs-64/

- One self-contained offline HTML file (Three.js inlined, all textures and audio generated in code)
- Desktop: WASD, mouse, E interact, I satchel, M map, F light, Shift hurry
- Phone: left joystick, drag right side to look, USE / BAG / MAP / LIGHT buttons
- Options: `?filter=near` for nearest-neighbour textures, `?lowh=180` to change internal resolution
